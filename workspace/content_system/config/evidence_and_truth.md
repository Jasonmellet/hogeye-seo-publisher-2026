## Hard rules

- Evidence outranks inference.
- If a claim cannot be tied to an approved source, omit it.
- Never invent metrics, customer stories, case studies, or warranty claims.
- Do not widen the product into surveillance, general security, or property-monitoring language.
- Treat WordPress as downstream distribution, not as the canonical editorial source.

## Approved source order

1. Official HogEye website
2. Approved internal docs in this repo
3. Approved strategy docs
4. DataForSEO
5. GSC
6. GA4
7. External factual sources only when clearly needed

## Output expectation

Every artifact should make it obvious:

- what source material was used
- what claims were allowed
- what claims were excluded
- what positioning lock governed the writing
