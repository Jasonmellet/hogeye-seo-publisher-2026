## One-line brand truth

**HogEye is a wild hog trap monitor** — a purpose-built **wild hog trap camera system** that lets operators **monitor trap sites remotely, verify full sounder commitment, and trigger closure at the right moment**.

It is **not** a security camera, trail camera, or general property monitoring product.

## Trapping workflow (operational truth)

Content should teach this model, not generic "smart camera" fluff.

### Steel / corral trap workflow

1. Pre-bait and set up camera
2. Set trap and keep it baited
3. Watch live video (day or night)
4. **Trigger remotely** when criteria are met — not on a fixed check schedule

### Net trap workflow (Boar Blanket / drop net)

1. Pre-bait the hotspot; learn **when and how many** hogs
2. Put net up in **conditioning mode** (elevated on T-post ~7–10 ft so hogs slide under and feel the net)
3. Continue monitoring; **never let bait run out**
4. Switch from conditioning to **catch phase** remotely when full sounder is present
5. Drop/trigger the net — one well-timed drop = one massive catch

**Net nuance (Schell):** Net traps are more passive by nature than steel gates, but HogEye makes them **active** — switch conditioning → catch without driving to the site and educating hogs.

### Decision rules (behavior content backbone)

- **Do not trigger** before you know the **complete sounder** is in the trap
- Partial capture educates survivors → trap-shy hogs → program setback for months
- Passive/unmonitored traps can misfire and train hogs to avoid structures
- Whole-sounder removal is the only approach with lasting results
- Monitor **multiple days** to count sounder size before closure
- Summer: hogs cluster near water/wallows; if no natural water, create a mud hole with buckets

### What operators optimize for

- Full-sounder capture rate (not individual catches)
- Fewer wasted trips to empty traps
- Closing at 2am when the window opens — not the next morning after they've left
- Trigger reliability in weak cell coverage

## Messaging pillars (safe to repeat)

1. **Real-time remote triggering** — full control from anywhere; no guessing
2. **Proven field results** — Giles Island, Johnson Timber (2000+ hogs / 10 years), Delta Wildlife testimonials on site
3. **Off-grid power reliability** — solar + battery for remote trap sites (frame as **trap uptime**, not "off-grid security")
4. **Full visibility day or night** — live HD/IR feed to **count hogs before closing**
5. **Trap-specific app** — not a repurposed consumer camera app
6. **Works with existing traps** — corral, drop, net, custom
7. **US support + warranty** — 3-year replacement; real trappers on the phone

### HogEye vs. trail cameras (approved contrast)

| Trail cameras | HogEye |
|---|---|
| Photo bursts; 30–90 sec alert delay | Continuous live stream |
| No remote trigger | One-touch remote trigger |
| Designed for scouting/observation | Designed for **trap closure decisions** |
| "Set and forget" | Active monitoring + closure command |

The **"90-second problem"** is a valid teaching frame: by the time a trail cam alert arrives, the sounder may already be gone.

## Claims policy

### Allowed

- Product features on official HogEye pages
- Factual trap process descriptions
- External facts with clear sources (USDA APHIS, Texas A&M, etc.)
- Real testimonials on the site (Riley, Johnson, Acosta — attributed)

### Always prohibited

- Invented performance metrics
- Invented case studies or customer stories
- Unsupported comparative claims
- Wrong pricing tiers
- Calling Big Pig Traps DIY
- Security/surveillance use cases
- Claims about the unreleased Mini AI camera, including features, availability, or dates
- Screwworm treatment advice or veterinary protocols

**If you cannot source it, omit it.**

## North Star test

Every section must answer **at least one**:

1. How does this help remote hog trap monitoring?
2. How does this improve trap closure timing?
3. How does this improve full-sounder capture outcomes?
4. How does this reduce wasted trips or missed captures?

If not — cut it or reframe it.
