# HogEye Owner Rules Override

This file records owner feedback that overrides legacy wording.

If any older site copy, historical draft, or legacy SEO artifact conflicts with this file, follow this file.

## Hard rules (non-negotiable)

1. Never refer to the audience as `ranchers` in generated content.
2. Frame the product as a `wild hog trap monitor` and approved trap-monitoring variants only.
3. Do not broaden positioning into:
   - general property monitoring
   - ranch monitoring
   - surveillance
   - land security
   - perimeter security
   - driveway or gate security
4. If a claim cannot be verified by approved sources, omit it.

## Approved framing examples

- wild hog trap monitor
- wild hog trap camera system (use this; **do not** use “wild hog trap **release** camera system” in new copy, Schell April 2026; see `workspace/CLIENT_FEEDBACK_SCHELL_APR2026.md`)
- hog trap camera with remote trigger
- remote trap monitoring and closure
- sounder capture timing

**Legacy note:** Older materials may still say “wild hog trap camera system.” When editing or republishing, migrate to **wild hog trap camera system** unless preserving a historical quote.

## Prohibited framing examples

- off-grid security camera
- ranch security camera
- property surveillance system
- land monitoring platform
- all-purpose remote monitoring system

## Writing behavior required

- Prefer precise trap-operation language over broad benefit language.
- If an inferred use case is plausible but not approved, do not include it.
- If there is tension between inferred truth and approved brand truth, approved brand truth wins.
