# HogEye Pre-Submission QA Checklist
### Run this before every draft goes to Google Doc for client review

**Goal:** Catch everything the client would flag — before they see it.  
**Time to complete:** ~10 minutes per piece  
**Reference:** `HOGEYE_CONTENT_STYLE_GUIDE.md`

---

## 1. North Star Test (must pass all that apply)

Read each H2 section and ask: does this section answer at least one of these?

- [ ] How does this help remote hog trap monitoring?
- [ ] How does this improve trap closure timing?
- [ ] How does this improve full-sounder capture outcomes?
- [ ] How does this reduce wasted trips or missed captures?

**If a section answers none:** reframe it or cut it before submission.

---

## 2. Blacklist Scan (zero tolerance)

Search the draft for each term. If found, replace or remove.

- [ ] security camera
- [ ] driveway camera
- [ ] property security / perimeter security
- [ ] surveillance
- [ ] off-grid security
- [ ] ranch camera (as standalone — not "trap camera on a ranch property")
- [ ] trail camera (used generically without trap-specific context)
- [ ] game camera (in deer/wildlife context)
- [ ] hunting camera
- [ ] theft / burglary / deliveries
- [ ] gate access (as primary use case)

**Quick check:** Cmd+F each term in the Google Doc before sending.

---

## 3. Vocabulary Check

Verify these preferred terms are used where relevant:

- [ ] "sounder" used instead of herd/group/pack
- [ ] "conditioning" used instead of acclimation/training
- [ ] "operator" or "team" used instead of user/customer
- [ ] "closure window" or "closure criteria" used correctly
- [ ] "trap site" or "active zone" rather than "property" as primary frame
- [ ] "wild hog trap camera system" appears at least once (or "trap camera" with trap-specific context)

---

## 4. Structure Check

- [ ] Opens with a problem statement (not a product claim)
- [ ] HogEye is introduced after the problem/context is established — not in paragraph 1
- [ ] FAQ section present with 4–6 questions
- [ ] FAQ answers are 1–2 sentences — no padding
- [ ] CTA block is present at the end
- [ ] CTA uses outcome-framing ("Ready to run a tighter trap program?") — not "Buy now" language
- [ ] 4–5 internal links distributed through the body (not stacked)

---

## 5. SEO Metadata Check

- [ ] Meta title includes primary keyword and is under 60 characters
- [ ] Meta description is 140–155 characters
- [ ] Slug matches brief (lowercase, hyphens, no stop words)
- [ ] Primary keyword appears in H1
- [ ] Primary keyword appears in first 100 words of body
- [ ] At least 2–3 supporting keywords used naturally in body

---

## 6. Voice Spot-Check (read these sections aloud)

- [ ] **Opening paragraph:** Does it sound like a consultant who knows the work — or like a marketing writer?
- [ ] **Any paragraph over 5 sentences:** Is every sentence earning its space?
- [ ] **The HogEye section:** Does it feel earned, or forced?
- [ ] **FAQ answers:** Are they direct — or do they pad before getting to the answer?

---

## 7. Final Read-Through

- [ ] No sentence starts with "HogEye is the best..." or similar superlatives
- [ ] No statistics cited without a plausible source (USDA, Texas A&M, field-estimated)
- [ ] No claims about competitor products that could be disputed
- [ ] Word count is within brief target (±200 words is acceptable)
- [ ] Featured image alt text written and matches a trap/field scene — not a generic camera image
